# Authoritative Sources for ROS 2 Core Concepts

This document lists primary and secondary sources for understanding fundamental ROS 2 concepts, as required by Task 1.1.1.

## Primary Sources (Official ROS 2 Documentation)

1.  **ROS 2 Concepts**: The highest-level overview of the ROS 2 graph and concepts.
    -   URL: [https://docs.ros.org/en/humble/Concepts.html](https://docs.ros.org/en/humble/Concepts.html)

2.  **Nodes**: Detailed explanation of ROS 2 Nodes.
    -   URL: [https://docs.ros.org/en/humble/Concepts/Basic/About-Nodes.html](https://docs.ros.org/en/humble/Concepts/Basic/About-Nodes.html)

3.  **Topics**: Detailed explanation of ROS 2 Topics.
    -   URL: [https://docs.ros.org/en/humble/Concepts/Basic/About-Topics.html](https://docs.ros.org/en/humble/Concepts/Basic/About-Topics.html)

4.  **Services**: Detailed explanation of ROS 2 Services.
    -   URL: [https://docs.ros.org/en/humble/Concepts/Basic/About-Services.html](https://docs.ros.org/en/humble/Concepts/Basic/About-Services.html)

5.  **Actions**: Detailed explanation of ROS 2 Actions.
    -   URL: [https://docs.ros.org/en/humble/Concepts/Basic/About-Actions.html](https://docs.ros.org/en/humble/Concepts/Basic/About-Actions.html)

6.  **Launch Files**: Explanation of the ROS 2 launch system for running multiple nodes.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Creating-Launch-Files.html](https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Creating-Launch-Files.html)

## Secondary Sources (Tutorials and Guides)

1.  **ROS 2 Tutorials - TurtleSim**: The official introductory tutorials using `turtlesim`.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Beginner-CLI-Tools/Introducing-Turtlesim/Introducing-Turtlesim.html](https://docs.ros.org/en/humble/Tutorials/Beginner-CLI-Tools/Introducing-Turtlesim/Introducing-Turtlesim.html)

2.  **Robotics Back-End Blog - ROS 2**: A well-regarded blog with practical examples.
    -   URL: [https://roboticsbackend.com/category/ros2/](https://roboticsbackend.com/category/ros2/)
