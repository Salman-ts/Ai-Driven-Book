# Authoritative Sources for ROS 2 Python Client Library (rclpy)

This document lists primary sources for understanding the ROS 2 Python client library (`rclpy`), as required by Task 1.2.1.

## Primary Sources (Official ROS 2 Documentation)

1.  **`rclpy` Overview**: While there is no single high-level overview page, the documentation is structured around tutorials. The main entry point is the `rclpy` package documentation itself.
    -   URL: [https://docs.ros.org/en/humble/p/rclpy/index.html](https://docs.ros.org/en/humble/p/rclpy/index.html)

2.  **Writing a Publisher and Subscriber (Python)**: The most critical tutorial for understanding the basic pub/sub pattern in `rclpy`.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Py-Publisher-And-Subscriber.html](https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Py-Publisher-And-Subscriber.html)

3.  **Creating a ROS 2 Package**: A prerequisite for writing any ROS 2 node, this tutorial explains how to use `ros2 pkg create`.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Creating-A-ROS-2-Package.html](https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Creating-A-ROS-2-Package.html)

4.  **Building a ROS 2 Package**: Explains how to use `colcon build` to compile and install a ROS 2 package.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Building-A-ROS-2-Package.html](https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Building-A-ROS-2-Package.html)

## Secondary Sources (Community Examples)

1.  **ROS 2 Examples - `rclpy`**: A GitHub repository maintained by the ROS 2 core team containing a wide variety of `rclpy` examples.
    -   URL: [https://github.com/ros2/examples/tree/humble/rclpy](https://github.com/ros2/examples/tree/humble/rclpy)
