# Authoritative Sources for NVIDIA Isaac Sim Capabilities

This document lists primary sources for understanding the features and architecture of NVIDIA Isaac Sim, as required by Task 1.11.1.

## Primary Sources (NVIDIA Documentation)

1.  **Isaac Sim Main Page**: The official landing page for Isaac Sim, providing a high-level overview of its features and capabilities.
    -   URL: [https://developer.nvidia.com/isaac-sim](https://developer.nvidia.com/isaac-sim)

2.  **Isaac Sim Documentation**: The official and most comprehensive source of information. Key sections include:
    -   **Core Concepts**: Explains the foundational technologies like USD, Omniverse, and the UI.
        -   URL: [https://docs.omniverse.nvidia.com/isaacsim/latest/core_concepts.html](https://docs.omniverse.nvidia.com/isaacsim/latest/core_concepts.html)
    -   **ROS & ROS 2 Support**: Details on the ROS/ROS 2 bridge and how to interface with Isaac Sim from a ROS network.
        -   URL: [https://docs.omniverse.nvidia.com/isaacsim/latest/features/robotics_simulation/ros_support.html](https://docs.omniverse.nvidia.com/isaacsim/latest/features/robotics_simulation/ros_support.html)
    -   **URDF Importer**: Instructions on how to import a URDF model into an Isaac Sim scene.
        -   URL: [https://docs.omniverse.nvidia.com/isaacsim/latest/features/urdf_importer.html](https://docs.omniverse.nvidia.com/isaacsim/latest/features/urdf_importer.html)

3.  **Omniverse Platform**: Isaac Sim is built on the Omniverse platform. Understanding Omniverse is key to understanding Isaac Sim.
    -   URL: [https://www.nvidia.com/en-us/omniverse/](https://www.nvidia.com/en-us/omniverse/)

4.  **Universal Scene Description (USD)**: The open-source 3D scene description format that is the foundation of Omniverse and Isaac Sim.
    -   URL: [https://openusd.org/](https://openusd.org/)

## Secondary Sources (Tutorials and Examples)

1.  **Isaac Sim Tutorials**: The official documentation includes a rich set of tutorials that are essential for learning the tool.
    -   URL: [https://docs.omniverse.nvidia.com/isaacsim/latest/tutorials/intro_tutorials.html](https://docs.omniverse.nvidia.com/isaacsim/latest/tutorials/intro_tutorials.html)

2.  **Open-Source Examples on GitHub**: NVIDIA provides a repository of example projects that demonstrate various Isaac Sim features.
    -   URL: [https://github.com/NVIDIA-Omniverse/IsaacSim-Samples](https://github.com/NVIDIA-Omniverse/IsaacSim-Samples)
