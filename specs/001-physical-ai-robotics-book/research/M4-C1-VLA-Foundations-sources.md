# Authoritative Sources for VLA Models and LLM Integration

This document lists primary sources for understanding Vision-Language-Action (VLA) models and the integration of Large Language Models (LLMs) into robotics, as required by Task 1.16.1.

## Primary Sources (Research Papers and Frameworks)

1.  **"SayCan: Learning Language-Conditioned Affordances in Generalist Robot Agents"**: A seminal paper introducing the concept of using LLMs for high-level task planning in robotics, by grounding language in robot capabilities.
    -   URL: [https://saycan.github.io/](https://saycan.github.io/)
    -   Paper: [https://arxiv.org/abs/2204.01691](https://arxiv.org/abs/2204.01691)

2.  **"PaLM-E: An Embodied Multimodal Language Model"**: A significant advancement that integrates visual and robotic control signals directly into a large language model.
    -   URL: [https://palm-e.github.io/](https://palm-e.github.io/)
    -   Paper: [https://arxiv.org/abs/2303.03378](https://arxiv.org/abs/2303.03378)

3.  **"Inner Monologue: Empowering LLMs as Active Robot Reasoners"**: Explores how LLMs can reason about tasks and interact with their environment by chaining together actions.
    -   URL: [https://innermonologue.github.io/](https://innermonologue.github.io/)
    -   Paper: [https://arxiv.org/abs/2307.05141](https://arxiv.org/abs/2307.05141)

4.  **Google Robotics - LLMs for Robotics**: Various blog posts and research overviews from Google on their work with LLMs in robotics.
    -   URL: [https://robotics.google/](https://robotics.google/) (Explore their research section)

5.  **Prompt Engineering Guides**: Understanding how to effectively prompt LLMs is crucial for integration.
    -   OpenAI's Prompt Engineering Guide: [https://platform.openai.com/docs/guides/prompt-engineering](https://platform.openai.com/docs/guides/prompt-engineering)
    -   DeepLearning.AI Short Course on Prompt Engineering: [https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/)

## Secondary Sources (Practical Implementations and Libraries)

1.  **LangChain / LlamaIndex**: Frameworks that facilitate building applications with LLMs by providing tools for chaining prompts, integrating with external data sources, and using LLMs for agents/tools.
    -   LangChain: [https://www.langchain.com/](https://www.langchain.com/)
    -   LlamaIndex: [https://www.llamaindex.ai/](https://www.llamaindex.ai/)

2.  **OpenAI API Documentation**: For practical implementation with OpenAI's GPT models, including function calling.
    -   URL: [https://platform.openai.com/docs/api-reference](https://platform.openai.com/docs/api-reference)
