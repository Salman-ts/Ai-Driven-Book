# Authoritative Sources for ROS 2 Packages & Launch Architecture

This document lists primary sources for understanding advanced ROS 2 packaging and launch file architecture, as required by Task 1.4.1.

## Primary Sources (Official ROS 2 Documentation)

1.  **Creating Launch Files**: The foundational tutorial for the ROS 2 launch system.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Creating-Launch-Files.html](https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Creating-Launch-Files.html)

2.  **Advanced Launch File Concepts**: A guide to more complex launch file features, including substitutions, arguments, and event handlers.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Using-Substitutions.html](https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Using-Substitutions.html)
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Launch-Main-Zombies.html](https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Launch-Main-Zombies.html) (Event Handlers)

3.  **Managing Large Projects (Metapackages)**: The official documentation on using `<exec_depend>` and creating metapackages to group related packages together.
    -   URL: [https://docs.ros.org/en/humble/How-To-Guides/Package-Management/Creating-Metapackages.html](https://docs.ros.org/en/humble/How-To-Guides/Package-Management/Creating-Metapackages.html)

4.  **Passing Parameters**: How to set node parameters from a launch file, including loading from a YAML file.
    -   URL: [https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Using-Parameters-In-A-Launch-File.html](https://docs.ros.org/en/humble/Tutorials/Intermediate/Launch/Using-Parameters-In-A-Launch-File.html)

5.  **Python Launch Files**: Specific documentation on the `launch_ros` Python library.
    -   URL: [https://github.com/ros2/launch_ros/tree/humble/launch_ros](https://github.com/ros2/launch_ros/tree/humble/launch_ros)

## Secondary Sources

1.  **ROS 2 Best Practices**: A collection of community-driven best practices for structuring ROS 2 projects.
    -   URL: [https://github.com/leggedrobotics/ros_best_practices/wiki](https://github.com/leggedrobotics/ros_best_practices/wiki)
